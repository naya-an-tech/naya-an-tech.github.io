[GitOps] git action local 환경 구축 (with act)

act를 활용하여 로컬 gitflow 테스트 환경 구축

#gitops#k8s#act#local-setting#environment#깃옵스#로컬환경구축

develop branch 가 업데이트되거나, pr이 생성되었을 때마다 테스트를 실행하거나, release tag가 생성되어 프로덕션을 빌드를 자동화하기위해 gitops, workflows를 작성하곤한다.

매번 git repo에 올려가며 테스트해왔으나, 번거로움이 많아 로컬에서 동일한 환경을 구축하여 git action을 테스트 해본 뒤 커밋하기위해 로컬 환경을 구축해보자.

Act 설치

먼저 act를 설치합니다.

brew install act

설치가 완료되었다. act는 도커를 사용하고있으므로, 도커가 미리 설치되어있어야합니다.

작업중인 repo로 진입하여 아래의 workflow들을 확인해 본다.

workflow 기본 명령어

# 기본 workflow 목록 가져오기
act -l

# m 시리즈 mac일 경우
act -l --container-architecture linux/amd64

# 특정한 job들만 확인하기
act -j job_name -l

workflow 로컬에서 실행

# (기본)
act

# (기본), m시리즈 mac일 경우
act --container-architecture linux/amd64

# 특정 이벤트 트리거
act pull_request

# 특정한 job만 실행하기
act -j job_name

# 특정한 workflow만 실행하기
act -j jobID -W .github/workflows/[Selected-Workflow].yml

SECRET 설정

실행시 arg로 넘기기

act -s KEY=VALUE

파일로 관리하기 my.secret

실습

.github/workflows 경로에 deploy.yaml 을 하나 작성합니다.

name: Deploy to Kubernetes

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Kubernetes CLI
      uses: azure/setup-kubectl@v1
      with:
        version: v1.21.0

    - name: Authenticate to Kubernetes cluster
      run: |
        echo "${{ secrets.KUBE_CONFIG }}" | base64 --decode > $HOME/.kube/config

    - name: Deploy to Kubernetes
      run: |
        kubectl apply -f k8s/

워크플로우 목록 확인하기

act -l 로 워크플로우 목록을 확인합니다.

m시리즈 맥북의경우 아키텍쳐 경고가 나옵니다. —container-architecture linux/amd64 옵션을 추가합니다.

특정 워크플로우 실행

하나의 워크플로우를 전체 실행하고싶다면 -W 옵션으로 workflow yaml을 지정하여 실행

act -W .github/workflows/deploy.yaml

특정 잡 실행

-j 옵션을 통해 -l 리스트에서 본 job id 로 실행합니다.

act -j deploy
